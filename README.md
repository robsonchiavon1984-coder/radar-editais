# Radar de Editais

Painel de estudo para os concursos TRF5, TJRS, TJSC e SEFAZ/SC: pontos dos editais, normas vinculadas, precedentes classificados por ponto, alterações legislativas 2023–2026, assuntos mais cobrados e cronograma.

Tudo está num único arquivo (`index.html`), sem servidor e sem dependências além das fontes do Google Fonts.

## Publicação no GitHub Pages

1. Crie um repositório e envie os arquivos desta pasta (`index.html`, `.nojekyll`, `robots.txt`, `README.md`).
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
4. Em um ou dois minutos o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/` fica disponível.

## Marcações de leitura e conclusão

As marcações (leis lidas, julgados lidos, pontos concluídos, cronograma) e as personalizações ficam salvas **no navegador** em que forem feitas. Para levá-las a outro aparelho, use o botão ⚙ → **Baixar arquivo .json** e, no outro aparelho, ⚙ → **Abrir arquivo .json** → **Importar**.

## Impressão / PDF

Botão ⎙ no topo: painel, edital completo ou disciplina, catálogo de normas, precedentes da disciplina, alterações legislativas, cronograma e assuntos mais cobrados, em A4 paisagem.

## Atualização

Para atualizar, substitua o `index.html` pela versão nova e faça o commit.
